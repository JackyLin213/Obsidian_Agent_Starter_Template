# PARA 方法論在知識管理中的核心邏輯

> [!QUOTE] 💎 核心陳述 (One-Sentence Thesis)
> PARA 依據資訊與當下行動的緊密程度（Actionability）而非靜態學科主題將數位環境劃分為四層，從根本上解決傳統分類法容易淪為數位死水的問題。

## 📖 概念闡述 (Concept Explanation)
傳統以「主題/領域（如歷史、程式、心理學）」建立資料夾的做法，往往在歸檔時面臨分類困難，檢索時更因脫離具體工作情境而無法快速取用。

PARA 透過四個清晰維度動態組織資訊：
1. **Projects (專案)**：具備明確死線（Deadline）與具體產出目標的短期任務。
2. **Areas (領域)**：需要長期維持水準與投入的責任範疇（例如：身心健康、團隊管理）。
3. **Resources (資源)**：未來可能感興趣、具長遠參考價值的主題資產與知識庫。
4. **Archives (歸檔)**：已完成或已終止的專案與非活躍資料。

### 與卡片盒筆記（Zettelkasten）的互補關係
PARA 的 `Resources` 是實踐卡片盒筆記法（Zettelkasten）的最佳溫床。在 Resources 中沉澱的原子卡片（[[卡片盒筆記法的原子性原則 (Atomicity Principle)]]）可以隨時被不同時期的 `Projects` 引用與重組，達成跨專案的知識複用。
