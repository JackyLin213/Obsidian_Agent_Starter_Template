# @TiagoForte_2022_打造第二大腦核心精華

> [!ABSTRACT] 📑 執行摘要 (Executive Summary)
> Tiago Forte 在《打造第二大腦》中提出 CODE 模型（Capture 獲取、Organize 組織、Distill 提煉、Express 表達）與 PARA 分類法。其核心主張在於知識管理應以「行動導向」而非主題分類，並透過漸進式總結法（Progressive Summarization）在不消耗過多認知負擔的前提下逐步沉澱高價值知識。

## 💡 核心論點與關鍵洞察 (Key Insights)
1. **以行動為導向的組織法（Organize by Actionability）**：人類大腦不擅長在龐大的主題資料夾中檢索資料，PARA 依據「與當前行動的緊密程度」將資訊分流至專案（Projects）、領域（Areas）、資源（Resources）與歸檔（Archives）。
2. **漸進式總結法（Progressive Summarization）**：避免一次性過度總結；在每次重訪筆記時，透過畫重點、標粗體、寫摘要逐步提煉，將資訊壓縮成可迅速調用的心智資產。
3. **第二大腦的終極目標是產出與表達（Express）**：筆記不是收藏品，而是為了未來的創造與行動服務。

## 📝 結構化內容整理 (Structured Notes)

### 1. CODE 模型架構
- **Capture (獲取)**：只保留引起共鳴（Resonance）的資訊，避免成為數位囤積狂。
- **Organize (組織)**：依照 PARA 架構，優先考慮「這項資訊能在哪個專案中派上用場？」。
- **Distill (提煉)**：尋找核心本質，將長文萃取為原子概念。
- **Express (表達)**：將積累的模組化中間產物（Intermediate Packets）組裝成最終產出。
