# 靈感 - AI Agent 輔助卡片盒筆記流轉的自動化邊界

> [!NOTE] 💡 靈感背景 / 痛點概述
> 當前許多人嘗試用 LLM 全自動生成幾百篇卡片筆記，結果知識庫迅速變成充斥 AI 幻覺與模板化廢話的垃圾場。核心痛點在於：**AI 應該負責「繁重體力活（清洗、提取結構、補齊元數據）」，而「價值判斷與深層理解」必須由人類把關**。

## 🎯 核心問題 / 洞察
- **兩階段蒸餾**是保持高信噪比的關鍵防線：文獻筆記可以讓 AI 自由整理，但只有經過審閱的高價值概念才能升格為永久原子筆記（[[卡片盒筆記法的原子性原則 (Atomicity Principle)]]）。
- 自動建立雙向連結時，必須結合 MOC 主題地圖導航，避免盲目產生孤立的死鏈接。
